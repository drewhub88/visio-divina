## 📖 Project Overview

Most devotional sites run on generic blog themes, which is like trying to read a novel in a spreadsheet. A devotional post has its own rhythm: a key verse, a story, reflection questions, a closing prayer, but standard WordPress themes don't know any of that. So the verse gets buried, painful to re-read reflections based on a certain theme or just browse old reflections. Rather than stick another plugin on top of a theme that was never designed for this work, I started with what a devotional actually *needs* and built a theme for it.


### On the name: Visio Divina
**Visio Divina** means "divine seeing" — the visual complement to *Lectio Divina* (prayerful reading). It's about sitting with an image, letting it draw you in, rather than rushing past. Felt fitting for a theme where the verse and the illustration get as much visual weight as the text.

## 🎨 Features

- Custom post types for devotional characters and guest articles
- Monthly theme and character taxonomies for organisation
- A devotional archive page with filters and search
- Dedicated pages for figures, contributors, contact, donations, and submissions
- Three custom sidebar widgets (calendar, theme index, recent posts)
- Mobile-friendly
